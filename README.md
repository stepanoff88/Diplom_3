# Diplom_3 — автотесты Stellar Burgers

Это третий дипломный проект — UI-автотесты для Stellar Burgers на Java 11.
Проверил регистрацию, все четыре способа входа, личный кабинет, выход из аккаунта
и переходы между разделами конструктора.

- Элементы страниц вынес в Page Object; 
- Тестовых пользователей создаю и удаляю через API;
- Шаги размечены @Step и собираются в Allure; 
- Тесты гоняются в Google Chrome и Яндекс.Браузере.
